# Odoo Asset Management

A custom Odoo module for managing company assets and asset borrowing workflows.

## Overview

This project explores ERP module development using the Odoo framework and Python. It focuses on asset data management, borrowing records, and business validation.

## Features

- Asset master data management
- Asset borrowing records
- Relational data modeling
- Borrowing quantity validation
- Computed fields and business logic

## Tech Stack

- Python
- Odoo Framework
- Odoo ORM
- PostgreSQL
- XML

## Learning Objectives

- Understanding Odoo module architecture
- Working with Odoo ORM
- Implementing Many2one and One2many relationships
- Developing computed fields and model constraints
- Understanding relational database integration
